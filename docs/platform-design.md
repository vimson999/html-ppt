# 案例平台与课件交付

## 已确认范围

- 案例中心展示封面、简介、标签，支持关键词及学科、年级、互动类型筛选。
- 案例详情说明学习目标、教学流程、使用条件和技术来源，提供演示及下载。
- 课件为独立的沉浸式教学场景；地球案例使用 Three.js 和 GSAP 升级。
- 每个案例可下载 ZIP，包含其自身文件、声明的共享资源与类库、许可证以及启动说明。
- 保留原有教学内容和计算正确性；为不支持 WebGL 的设备提供明确提示和二维兼容模式。

## 信息与交付

`experiment.json` 是案例信息的唯一编辑来源。构建扫描案例目录，生成 `catalog/experiments.json`，详情通过完整案例键（学科/年级/主题/实验编号）定位，避免不同主题下 exp-001 冲突。

类库固定版本，浏览器构建与许可证保存在 shared/vendor。案例只声明实际使用的类库和共享文件；ZIP 保持必要的相对目录结构，包含独立入口和无第三方依赖的 Node.js 本地服务。不宣称双击 HTML 可用。

平台保持静态网站，不需要用户账户或服务器数据库。`npm run build` 生成可部署的 dist 及下载包；`npm run dev` 先构建，再提供源文件预览。

## 验收

检查搜索组合和空结果、详情的有效与无效地址、演示返回、实际 ZIP 下载及解压后的独立运行。确认 Three.js WebGL 场景、GSAP 镜头过渡和既有模型测试；检查手机布局、无外部资源请求、减少动态效果偏好以及兼容模式。
