# 地球自转与昼夜交替

七年级地理互动课件，适用于 15–20 分钟课堂探究。当前为可试用原型，尚无真实课堂反馈。

## 打开课件

在项目根目录运行 `npm run dev`，从实验台选择本课，或访问：

http://localhost:5173/experiments/geography/grade-7/earth-rotation/exp-001/index.html

## 教学路径

1. **发现问题（2 分钟）**：北京午间与纽约深夜的跨洋通话，提出昼夜成因猜想。
2. **动手探索（8 分钟）**：同一时刻比较北京与纽约；追踪北京通过昏线；从北极上空俯视判断自转方向。
3. **挑战一下（4 分钟）**：三题即时反馈，分别检查昼夜成因、方向、半周后的昼夜变化。
4. **带走知识（2–4 分钟）**：区分昼夜现象和昼夜交替，并用手电筒与球复述成因。

重难点：地球的不透明球体形态产生昼夜；地球自转导致一个地点的昼夜交替。地点切换保持同一模型时刻，不能把观察视角的变化混同为自转。

## 交互

- 拖动地球或聚焦后使用方向键：调整相机视角，不改变时间。
- 播放 / 暂停：推进 / 冻结自转；1× 为 60 秒模拟一天，可选 2×、4×。
- 时间滑杆和四个时刻按钮：改变选中地点的地方太阳时，并暂停播放。
- 选择城市：比较同一时刻不同经度的昼夜；提供北京、伦敦、纽约、悉尼、基多。
- 北极上空：正上方俯视，验证逆时针自转。面向地点：将当前地点置于视野中心，之后相机保持不动。
- 重置：恢复北京正午、斜侧视角、1×、经纬网开启及暂停状态，不清除答题结果。
- 三题全部完成后可重新挑战。四个教学环节可随时切换。
- 教学提示 / 资料与来源：原生弹窗，支持 Escape 关闭；全屏使用共享工具。
- 默认暂停；切到其他浏览器标签时暂停，避免后台继续推进课堂场景。

## 模型边界

采用正交投影球体。太阳沿固定方向平行照射、直射赤道，忽略公转、季节变化、大气折射、地形和太阳视半径。因此非极点地点的日出 / 日落近似为地方太阳时 6 时 / 18 时，不可用于真实日出预测。明暗采用同一个世界坐标系中的太阳方向点积，晨昏线为点积等于零的大圆。

本课的日常尺度为约 24 小时一周。精确的恒星日约 23 时 56 分，与太阳日存在差异；该差异只在教学提示说明，不进入本课基础题。地方太阳时不等同于北京时间或其他时区的法定时间。地球尺寸、光线距离、动画速度不按真实比例。

## 文件与来源

- `model.js`：模型时间、地理坐标与相机坐标换算。
- `globe.js`：Canvas 球体、海陆纹理、光照、晨昏线及地点标记。
- `main.js`：课堂控制与活动、练习反馈。
- `data/land.geojson`：Natural Earth 1:110m 陆地轮廓，公共领域；来源和校验值见 `data/SOURCES.md`。
- 科学参考：[NASA · What Is Earth?（Grades 5–8）](https://www.nasa.gov/learning-resources/for-kids-and-students/what-is-earth-grades-5-8/)。城市坐标为教学近似值。

不依赖第三方运行时类库、远程字体或外部 API。页面运行时所有资源均为本地资源；断网时仍需启动本地 HTTP 服务，不支持直接双击 HTML。

## 验证

根目录运行 `npm run check` 检查实验登记；运行 `node --test experiments/geography/grade-7/earth-rotation/exp-001/tests/model.test.mjs` 验证地方太阳时、明暗匹配、半周变化与北极视角方向。浏览器检查应覆盖播放暂停、视角、地点、四个时刻、练习、重置和窄屏布局。
